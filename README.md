# Bella Clinic OS

EEstamos iniciando o desenvolvimento da Bella Clinic Platform (Bella IA) para a clínica Esthetic Center.

Trata-se de uma aplicação corporativa construída em React + TypeScript + Supabase.

O banco de dados (Bella Knowledge Graph v3.0) já está completamente modelado e será a única fonte da verdade. Não altere o schema do banco e não utilize dados mockados ou hardcoded.

O projeto seguirá uma arquitetura baseada em componentes reutilizáveis, camada de serviços, tipagem estrita em TypeScript e consumo de dados via Supabase.

Nesta etapa, não comece a implementar funcionalidades. Primeiro, analise o projeto, explique como pretende estruturá-lo e aguarde minhas instruções para iniciar a Sprint 0.9.
